CÓMO ABRIR EL PROYECTO EN INTELLIJ IDEA
---------------------------------------
1. Descomprime este archivo en una carpeta de trabajo.
2. En IntelliJ IDEA: File > Open... y selecciona la carpeta RegistroViajes_EP2_Base.
3. Si IntelliJ lo pregunta, elige "Trust Project" y abre el proyecto como proyecto Maven.
4. Verifica que el JDK del proyecto sea 21 (File > Project Structure > Project).

CÓMO EJECUTAR LA APLICACIÓN
---------------------------
- Ejecuta la clase Launcher (botón Run junto al método main).
- La clase App carga la vista principal desde:
      src/main/resources/cl/duoc/viajes/view/main-view.fxml
  Debes crear ese archivo con Scene Builder. Mientras no exista, la aplicación
  se detiene con el mensaje "No se encontró la vista principal".

ARCHIVOS DE DATOS
-----------------
- Los archivos viajes_vacaciones.json y viajes_estudios.json están en la carpeta
  raíz del proyecto (junto a pom.xml) y parten vacíos ([]).
- Tu aplicación debe leerlos al iniciar y actualizarlos cada vez que registres o
  elimines un viaje. Si se borran, la aplicación debe iniciar igual, con la
  tabla vacía y sin mostrar errores.

LO QUE DEBES AGREGAR AL pom.xml
-------------------------------
- La dependencia de la librería Gson, en el lugar indicado por el comentario.
  Luego recarga el proyecto Maven (ícono "Load Maven Changes" o
  clic derecho en pom.xml > Maven > Reload Project).

IMPORTANTE
----------
- No modifiques la lógica de las clases del modelo.
- No es necesario modificar Launcher ni App.
- Puedes agregar tus propios paquetes, clases y recursos al proyecto.

OPERACIONES DISPONIBLES EN EL MODELO
------------------------------------
Viaje (clase abstracta)
    getCodigoReserva() / setCodigoReserva(String)
    getDestino()       / setDestino(String)
    getSemanas()       / setSemanas(int)
    calcularCostoEstimado()   costo estimado del viaje en dólares (USD), según el tipo de viaje
    getTipo()                 "Vacaciones" o "Estudios"
    toString()                código de reserva y destino del viaje
    Los métodos set rechazan datos inválidos con un mensaje que explica el motivo:
        código de reserva: no puede ser nulo ni vacío
        destino:           no puede ser nulo ni vacío
        semanas:           entre 1 y 54

ViajeVacaciones (extiende Viaje, implementa Turistico)
    ViajeVacaciones(codigoReserva, destino, semanas, alojamientoIncluido)
    isAlojamientoIncluido() / setAlojamientoIncluido(boolean)
    tieneToursIncluidos()
    incluirTours()

ViajeEstudios (extiende Viaje)
    ViajeEstudios(codigoReserva, destino, semanas, costoCursoUsd)
    getCostoCursoUsd() / setCostoCursoUsd(double)
